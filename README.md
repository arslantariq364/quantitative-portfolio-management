# Quantitative Portfolio Management

Jupyter notebooks for exploring portfolio returns, volatility, drawdowns, Sharpe ratios, and Value at Risk. Included data files are `sample_prices.csv` and `Portfolios_Formed_on_ME_monthly_EW (1).csv`.

The notebooks are educational analyses. They are not an investment product and do not provide financial advice or guaranteed forecasts.

## Run the notebooks

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install numpy pandas matplotlib scipy jupyter
jupyter notebook
```

The main notebooks are `Returns Lab Basics.ipynb`, `Risk Adjusted Returns.ipynb`, and `LabSessionDrawdown.ipynb`.
